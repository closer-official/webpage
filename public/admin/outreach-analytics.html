送付・フェーズ分析

メインは送信済み相当（message_sent / resend_wait / resend_sent / resend_unavailable / no_outreach_channel）→ヒアリングに入った案件だけを対象に、直前の「送信済み操作」ログから templateId と 曜日・時（日本時間）をさかのぼって表示します。ファネルのパーセントはダッシュボード上の現在フェーズ件数で、例として送信済相当→ヒアリングは ヒアリング件数 ÷（送信済相当件数＋ヒアリング件数）です（絞り込みと同じ条件の送信済み案件のみ）。

絞り込み

下の集計・表は、ここで絞った期間・保存先・区分のログだけを対象にします。

エリア別 送信数・進行率

住所の都道府県ごとに、送信数（message_sent）と進行率（送信済み相当→ヒアリング）を図式化しています。進行率の分母は 送信数 + ヒアリング遷移数 です。

ファネル（件数・割合）

先頭の「送信済み→ヒアリング」% ＝ ヒアリング件数を分母（送信済＋ヒアリング）で割った値（SNSなしは分母に含めません）。2段目以降も同様に次フェーズ件数 ÷（前段＋次段）。件数はいずれもダッシュボードの現在状態（メール送信済み案件）。契約は内部値 contracted（画面の契約済）です。

送信済み相当 → ヒアリング（さかのぼり）

上記遷移がログに残っている案件のみ。送信操作ログが無い場合は template / 曜日・時が空または「不明」になります。
