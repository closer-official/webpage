店舗ドラフト編集（作業者用）

ベーステンプレを選び、文章・写真URL・SEOを保存します（配色の選択 UI は置いていません。雰囲気は画像 URL で変えてください）。
編集フォームの項目は選んだベーステンプレに合わせて切り替わります（cafe_1 だけ店主・お品書き・MEO など拡張項目が出ます。埋め込み型は名前・キャッチ・SEO中心）。
保存先は /api/template-customizations（この編集画面だけ管理者ログイン必須）。共有用の /api/template-preview/<カスタムID> を第三者が開くときはアプリのログインは不要です（ホスティング側でサイト全体にパスワードがかかっている場合は別）。左の枠は常にフォーム内容のライブプレビューです。

管理者ログイン

ライブプレビュー 左は常にフォームから生成したライブプレビューです。下の共有URLは最後に保存した内容（LINE等のリンクプレビューもこちら）。編集直後は左とURLが一致しないことがあるので、共有前に保存してください。

1. ドラフトの選択

Gemini 一括入力（文章だけ・最大2万文字）

Googleのまとめ・食べログの要約などをそのまま貼り付け。サーバーで Gemini が店名・キャッチ・住所・MEO・メニュー行・FAQ・セクションなどを読み取ります。 取れた項目だけいまのフォームに上書きし、空だった項目はテンプレ／既存入力のままです。セクションは同じ id があれば中身だけ差し替え、無い id は末尾に追加します。メニュー・FAQ・店舗ブロックは、返ってきた行が1件以上あるときだけそのリストを置き換えます。

地図を埋め込む（コピペ）

Googleマップの「共有」→「地図を埋め込む」→「HTMLをコピー」の iframe 全文、または埋め込みURL／短縮リンクを貼り付けます。下の「地図 iframe 埋め込みURL」に反映され、空欄ならフローティング地図等も同じURLで埋まります。貼り付け後しばらく待つか「地図URLに取り込む」を押してください。

送付案件との紐づけ（このドラフトとダッシュボード1件）

プレビューURL・配信停止URL・営業フェーズを、この場所からまとめて扱えます。フェーズは OK済・送信済の案件のみ変更できます（送付・フェーズ管理と同じ5段階）。返信待ちは開始から3か月後に自動で送信待ちになります。

3. 検索表示（SEO）

専門知識は不要です。上の店名・ページタイトル・キャッチ・住所を書いておけば、空欄の項目は自動で下書きが入ります（Googleの検索結果に出るタイトル・説明文のイメージです）。気になるところだけ直してください。

保存後にカスタム ID が確定します。プレビュー URLをコピーするか、メール作成画面を開いて本文に貼って送ってください（メールはブラウザの mailto）。このURLを開く相手に、このサイトの管理者ユーザー名・パスワードは不要です。
