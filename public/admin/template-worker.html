店舗ドラフト編集（作業者用）

ベーステンプレを選び、文章・写真URLを保存します（配色の選択 UI は置いていません。雰囲気は画像 URL で変えてください）。
編集フォームの項目は選んだベーステンプレに合わせて切り替わります（cafe_1 だけ店主・お品書き・MEO など拡張項目が出ます）。
保存先は /api/template-customizations（この編集画面だけ管理者ログイン必須）。共有用の /api/template-preview/<カスタムID> を第三者が開くときはアプリのログインは不要です（ホスティング側でサイト全体にパスワードがかかっている場合は別）。左の枠は常にフォーム内容のライブプレビューです。

管理者ログイン

ライブプレビュー 左は常にフォームから生成したライブプレビューです。下の共有URLは最後に保存した内容（LINE等のリンクプレビューもこちら）。編集直後は左とURLが一致しないことがあるので、共有前に保存してください。
サーバーでライブプレビューを描画しています。完了までそのままお待ちください。

1. ドラフトの選択

Gemini 一括入力（文章だけ・最大2万文字）

Googleのまとめ・食べログの要約などをそのまま貼り付け。サーバーで Gemini が店名・キャッチ・住所・MEO・メニュー行・FAQ・セクションなどを読み取ります。 取れた項目だけいまのフォームに上書きし、空だった項目はテンプレ／既存入力のままです。セクションは同じ id があれば中身だけ差し替え、無い id は末尾に追加します。メニュー・FAQ・店舗ブロックは、返ってきた行が1件以上あるときだけそのリストを置き換えます。

地図を埋め込む（コピペ）

Googleマップの「共有」→「地図を埋め込む」→「HTMLをコピー」の iframe 全文、または埋め込みURL／短縮リンクを貼り付けます。下の「地図 iframe 埋め込みURL」に反映され、空欄ならフローティング地図等も同じURLで埋まります。貼り付け後しばらく待つか「地図URLに取り込む」を押してください。

一括投入（最大10件・列フロー）

新規モードで下のボタンからベーステンプレを選び、表に入力して一括実行してください（従来型に切り替えるとドロップダウンでも選べます）。行ごとに 名前→重複（初回）→Gemini→マップ→SNS→最終確認→自動保存の順です。下の送付案件のプルダウンは一括保存の紐づけにも使われます。「フォームへ」で詳細フォームに載せたあと、従来型に切り替えて保存・プレビュー共有もできます。

# 名前 管理用ドラフト名（80字以内） 重複 店名らしさで初回照会 Gemini マップ IG X TikTok 確認 保存直前の要約 調整 詳細フォームへ 結果
送付案件との紐づけ（このドラフトとダッシュボード1件）

プレビューURL・配信停止URL・営業フェーズを、この場所からまとめて扱えます。フェーズは送付管理と同じ7種類のプルダウンです（送信前／送信済み／SNSなし・ウェブページ制作不可／ヒアリング中／提案中／契約済み／失注）。提案中のままフォロー開始から3か月経過すると、自動で送信済みに戻ります。

2. 本文・画像・URL

SNS（フッターアイコン）URL

Instagram・LINE・X（Twitter）は折りたたみの外に固定しています。

ラーメン弐：クイック情報バー

ヒーロー画像のすぐ下に表示される黒帯のバーです。営業時間・定休日・最寄り駅など、来店に必要な情報を手短に入れてください。

美容室 mellow：編集の目安（8区分）

黄 店名・副題（サイト名・ページタイトル・ヒーロー）／ 青 営業時間／ 黄緑 支払い方法／ 赤 電話番号／ 水色 店の想い・こだわり（Concept 本文・Our Policy 各項目）／ 紫 メニュー（トップ6カードなど）／ ピンク スタッフ名・紹介文／ 橙 住所・地図。写真は貼り付けでは変えません（テンプレのまま。ヒーロー画像URLは下の共通欄で手動変更）。

「WEB予約」ボタン類はこのURLを別タブで開きます。空欄のときは従来どおりサイト内の予約ページへ遷移します。

ラーメン等と同様、Google が発行する iframe タグを貼ってください。反映時は src のみ検証し、安全な iframe 1本として Access に表示します。空欄時は「地図 iframe 埋め込み URL」（cafe 欄）の URL を利用します。

HP 貼り付け取り込み

ホットペッパービューティー等の店舗説明をそのまま貼り付け、「取り込み」で上記8区分に推測で流し込みます（写真・星評価は無視）。ホットペッパー店舗URL・地図 iframe が本文に含まれていれば遷移先・地図欄にも入ります。 data-bind 版の専用ツール（解析・編集・プレビュー・HTML出力）は別ページで開けます（ローカル単体でも可）。

テキストスロット（LP 全文）

HTML は書かずにここだけで差し替えできます。改行はそのまま反映されます。ヒーロー見出しは「メイン見出し」欄とも連携します（スロットが空のとき共通欄を使います）。
